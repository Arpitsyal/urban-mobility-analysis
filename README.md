# Urban Mobility Analysis Using Tableau

## Project Overview
This project analyzes public transport operations to understand passenger demand, route performance, and service capacity.

## Objectives
- Analyze passenger boardings and alightings.
- Identify busy routes and stops.
- Compare passenger demand across time periods.
- Evaluate vehicle load and capacity utilization.
- Identify potential areas for service improvement.

## Tools Used
- Tableau
- Python (Pandas), if applicable
- Excel or CSV

## Key Findings
Add 3–5 findings based on your actual dashboard results.

- Highest-demand routes or stops: Route 18 shows highest boarding activity
- Peak passenger time periods: Afternoon, utilization increases again and approximately around 16:00–17:00(about 29%) highest levels are observed.
- Routes with high vehicle occupancy: Route 109 shows highest average V/C with approximately 32.7% in selected routes
- Potential service improvement areas: Dataset is primarily focused on weekday bus demand, that’s why direct comparison is not possible between weekday and weekend passenger behavior. There are some variables like Delay in the dataset, passenger satisfaction, emission and different transport weekday which are not available in the dataset. That’s why these aspects were not included in the analysis. That’s how, recorded boardings cannot be kept equivalent with unique passengers, and boarding activity can be separately represented because of different points of same passenger journey.
